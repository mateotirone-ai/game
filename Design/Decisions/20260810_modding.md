# Decision: Modding

- Status: **Accepted**
- Date: 2026-08-11
- Related: Multiplayer (megaworld integrity), online-model, Vision

## Context

Creative chose **later (B)** — mod/data hooks after the core game ships; not a launch pillar.

## Decision

- **No official modding platform at launch** — first-party content and tools first.
- **After core ships:** expose data/mod hooks (DataAssets, tables, safe content pipeline) so private worlds can extend.
- **Megaworld:** mods must not undermine server authority or economy (private-realm mods by default; curated/approved only if ever on mega).
- Do not block First Playable or mid-systems on mod tooling.

### Sequencing

| Phase | Scope |
|-------|--------|
| Launch / core | First-party only |
| Post-core | Documented data hooks + private-world mods |
| Later | Optional curated mega content if ever justified |
