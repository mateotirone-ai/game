# Decision: Animals

- Status: **Accepted**
- Date: 2026-08-10
- Related: Combat, Economy, biomes, security meters

## Decision

- **Livestock** matter (farm products, later renewable goods).
- **Wildlife** matter: hunting + threat.
- Wildlife intensity: **frontier-varies** — harsher in sparse / frontier biomes; calmer near dense civilization, matching Eve-like security bands.

## Sequencing

| Phase | Scope |
|-------|--------|
| First Playable | Optional ambient animals; no full livestock sim required |
| Next | Simple hunting + livestock on farms |
| Later | Biome wildlife tables tied to security bands |

## Consequences

- Farm buildings may gain livestock modules later.
- Security meter can include wildlife pressure.
