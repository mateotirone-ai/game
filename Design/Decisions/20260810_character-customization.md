# Decision: Character Customization

- Status: **Accepted**
- Date: 2026-08-10
- Related: Vision (no P2W), Multiplayer, Building (uniforms), buy-once monetization

## Context

Creative chose **deep (C)** character look / identity: rich creator, plus town uniforms / ranks later.

## Decision

- **Character creator** is deep — body, face, hair, outfit / early clothing, readable in first person and on others at gameplay distance (soft stylized, controller-friendly).
- **Later:** settlement **uniforms**, ranks/offices, and role kit cosmetics (guard, diplomat, etc.) that signal identity without granting combat/econ power.
- Monetization stays **buy-once / no P2W** — cosmetics must not sell power (already locked in world-systems).
- Phoenix continuity: appearance persists on the settler account across deaths unless the player changes it.

### Sequencing

| Phase | Scope |
|-------|--------|
| First Playable | Presets or light creator OK if it doesn’t block gather/build exit criteria |
| Next | Full creator pass |
| Mid | Equip slots, dyed kits, office/uniform overlays |
| Later | Rank/insignia, town livery systems |
