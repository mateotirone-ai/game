# Decision: Difficulty

- Status: **Accepted**
- Date: 2026-08-11
- Related: online-model, animals, food-chain, Combat, Multiplayer

## Context

Creative chose **granular sliders (C)** for private worlds; megaworld stays fair/fixed (or light).

## Decision

### Private / local worlds

- **Granular difficulty sliders** — at least: wildlife threat, spoilage, combat pressure, and peers as designed (hydration drain, raid frequency, etc.).
- Host/owner configures before or during the private realm; changes should be auditable so players know the rules.

### Shared megaworld

- **Fixed (or light) baseline** — no personal sliders that let one player soften the live economy/PvP for themselves.
- Optional realm-wide seasonal events later; not per-player god mode.

### Sequencing

| Phase | Scope |
|-------|--------|
| First Playable | Single tuned feel |
| Next | Private presets as shortcuts into slider sets |
| Mid | Full granular private sliders |
| Later | Megaworld light seasonal modifiers if desired |

## Locked interview answers

1. Difficulty → **C** granular private sliders; megaworld fixed/light
