# Decision: Win Condition vs Endless

- Status: **Accepted**
- Date: 2026-08-10
- Related: Progression, lore-narrative, Multiplayer, Vision

## Context

Creative chose **soft victories (B)**, **Minecraft-like**: meaningful triumphs exist; the world does not end.

## Decision

- The persistent world is **endless** — no hard “you won, server over” state.
- **Soft victories** celebrate progress: advancements/achievements, age/era milestones, settlement stage triumphs, war/treaty moments, monuments — Minecraft-style “you did the thing” without resetting or concluding the universe.
- Optional dragon-equivalent later (a big optional challenge) must still leave the world running.
- Prestige and chronicles record wins; play continues.

### Sequencing

| Phase | Scope |
|-------|--------|
| First Playable | Homestead→Hamlet as soft beat + journal foresight |
| Next | Advancement/achievement skeleton |
| Mid | Era/age victory banners tied to tech/stage |
| Later | Optional epic challenges; still no world-end |
