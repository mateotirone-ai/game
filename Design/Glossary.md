# Glossary

| Term | Meaning |
|------|---------|
| Phoenix | Player can die and return; continuity of self after respawn — not an unkillable god |
| Gravestone | Death marker that holds dropped / recoverable gear and goods |
| Settler | Playable character fantasy for early game (frontier founder) |
| Settlement | Player/NPC community with stages homestead → hamlet → village → town → city |
| Homestead | First settlement stage (First Playable) |
| Hamlet | Second settlement stage (First Playable stage-up) |
| Module | Snappable / terrain-aware building piece or functional station |
| Business | Enterprise with ledger, inventory, and optional employees |
| Specialty / Specialization | Regional or settlement focus that lowers costs / raises quality for a good set |
| Market | Local price discovery venue for goods |
| Contract | Binding trade or labor agreement with terms and penalties |
| Charter | Settlement constitution defining rights and offices (discovered over time) |
| Office | Government role with permissions |
| Treaty | Inter-settlement diplomatic agreement |
| Tech node | Unlock in the technology graph |
| Authority / Server | Simulation owner; dedicated server in target architecture |
| AIWorld | Simulated population, traders, and ambient systems |
| Game Feature | Modular Unreal plugin domain under `Plugins/GameFeatures/` |
| OFPA | One File Per Actor — preferred for collaborative maps |
| Controller-first | Gamepad is the primary UX target |

Update this file when introducing durable vocabulary in design docs.
