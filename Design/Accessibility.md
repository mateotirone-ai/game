# Accessibility

## Intent

A civilization game with deep systems must remain approachable and configurable.

## Requirements (target)

- **Full gamepad support** with remappable Enhanced Input actions.
- **Scalable UI** — text size, contrast, colorblind-safe market/region palettes.
- **Subtitles / important audio cues** with visual alternatives for combat and council alerts.
- **Difficulty / assistance** — optional economic advisors, hold-to-confirm toggles, camera assists.
- **Input alternatives** — keyboard/mouse parity without being the only viable path.
- **Performance scalability** — stylized art should offer low/medium/high paths for PC; consoles later use fixed profiles.

## Process

Accessibility reviews attach to major UI and combat milestones. Decisions that trade depth vs clarity go in `Design/Decisions/`.
